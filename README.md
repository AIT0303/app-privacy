# app-privacy

AIT0303 が公開するモバイルアプリの**プライバシーポリシー公開用**リポジトリ。

- 本体アプリのコードは各 Private リポジトリで管理。ここは審査で必須の「誰でも閲覧できる公開ポリシー URL」を提供するためだけの Public リポ。
- GitHub Pages で公開。

## 構成

```
index.html              一覧ページ
aws-skillcheck/         AWS スキルチェック
```

新しいアプリを追加するときは、`<app-slug>/index.html` を追加し、`index.html` の一覧にリンクを足すだけ。

## 公開 URL

- 一覧: https://ait0303.github.io/app-privacy/
- AWS 版: https://ait0303.github.io/app-privacy/aws-skillcheck/
